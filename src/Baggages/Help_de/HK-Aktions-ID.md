### Logische NFC-Aktions-ID

Zuordnung des Home-Key-Geräts zu einer bestehenden NFC-Aktion. Zulässig sind IDs von **0 bis 1499**.

Die ID wird nach erfolgreicher Authentifizierung an die bestehende NFC-Aktionsauswertung übergeben. Richten Sie die gewünschte Aktion und deren NFC-Zuordnung unter **Zutrittskontrolle** ein.

Jeder aktive Home-Key-Eintrag muss eine eigene Aktions-ID verwenden. Eine doppelte Aktions-ID sperrt die gesamte ETS-Berechtigungstabelle. Verwenden Sie diese ID nicht gleichzeitig für einen herkömmlichen UID-Tag.
